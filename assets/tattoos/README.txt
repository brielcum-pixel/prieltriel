- Keep originals. Do not upscale small files.
- Portrait and landscape both supported. Gallery uses object-fit cover
  without forcing destructive crops, plus a larger lightbox view.
- To add a new piece: save the file here, then add one entry
  to the PORTFOLIO array at the top of script.js.
